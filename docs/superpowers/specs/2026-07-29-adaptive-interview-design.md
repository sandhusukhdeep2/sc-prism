# Adaptive live-primary interview (2026-07-29)

Sukhdeep's ask: "in interview questions, you should utilize the real-time
primary AI to create the questions." Today the primary already runs mid-
interview (research brief + first-3-automations plan) but the QUESTION
SEQUENCE is scripted.

## Design

- Keep: the opening seed question(s) needed to bootstrap (business
  description), the research brief run, the plan draft, and all vault
  persistence exactly as today.
- Change: after the seed answer, each NEXT question is generated by one
  governed primary run: prompt = interview goal + answers so far + "ask the
  ONE next most useful question for setting up their AI workbench; reply with
  ONLY the question text, one sentence." Cap the adaptive phase (max 5
  questions) and per-run tokens (--token-budget 4_000, now available on run).
- HONESTY: if the generation run is a stub/timeout/non-real, fall back to the
  next unused SCRIPTED question and mark it visibly ("(standard question — no
  live model)") — the interview must never block on a provider and must never
  pretend a canned question was generated.
- Attribution: generated questions carry the same model-chip honesty the chat
  has (which model asked, 🔒 when local).
- No new egress; answers stay vault-side as today. Sensitivity floor
  unchanged (an answer with sensitive words routes the NEXT generation local).

## Tests

Generation prompt includes prior answers; stub → scripted fallback with the
honest marker; cap respected; token budget passed; existing interview tests
stay green.

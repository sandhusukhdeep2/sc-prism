# The project-room standard (Sukhdeep, 2026-08-29)

Load `docs/superpowers/specs/2026-08-29-project-room-design.md` and hold every
Work-page change to it. The short form:

1. A project is a separate ROOM: own chat, own folder access, own file
   details, unmistakable switching.
2. The work lives IN the chat — inline, scrollable, seat-attributed action
   lines derived ONLY from engine span records (never invented).
3. Attribution is three-part or it's not done: agent name · AI brand · action.
   "Opus is doing this thing" fails the bar.
4. The privacy line renders in the room: vault/MCP arguments never appear;
   🔒 withheld and ⛔ blocked are part of the story.
5. Every file the room mentions must be reachable from the room (reveal/open).

If a change cannot meet the bar honestly (data doesn't exist in spans), say
so in the PR/commit rather than faking a line.
